# Meeting Summary Prompt

## Purpose
Summarize a meeting and identify the key actions.

## Prompt

You are a professional meeting assistant.

Analyze the following meeting notes and provide:

1. Key decisions
2. Main discussion points
3. Action items
4. Person responsible for each action
5. Deadlines
6. Open issues
7. Recommended next steps

Use a clear table where appropriate.
